# Лабораторна робота №7. Аналіз бізнес-процесів з використанням IDEF0

**Варіант 1: Збут товару**

## Опис

Функціональна модель бізнес-процесу «Збут товару» побудована за методологією IDEF0 з рівнем декомпозиції не менше трьох.

### Структура моделі

- **A-0** — Контекстна діаграма (система як єдине ціле)
- **A0** — Декомпозиція на 5 підпроцесів:
  - A1. Прийняти замовлення
  - A2. Перевірити наявність
  - A3. Оформити продаж та оплату
  - A4. Підготувати товар
  - A5. Відвантажити товар
- **A1** — Декомпозиція прийому замовлення (рівень 3)
- **A5** — Декомпозиція відвантаження (рівень 3)

## Файли

- `report/` — Звіт у форматі DOCX
- `diagrams/` — Діаграми (зображення та файли Draw.io)

## Як відтворити в Draw.io

1. Відкрити [https://app.diagrams.net](https://app.diagrams.net)
2. Створити нову діаграму, встановити альбомну орієнтацію
3. Використати шаблон IDEF0 або намалювати прямокутники та стрілки згідно стандарту (ICOM)
4. Експортувати в PNG/PDF та .drawio
